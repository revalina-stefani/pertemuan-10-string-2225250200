## Tujuan
Mengolah dan menormalisasi data teks dengan string Python.

## Cara Menjalankan
Jalankan program dengan perintah:

python tugas/normalisasi_data_mahasiswa.py

## Algoritma
1. Membaca nama mahasiswa dan kode kelas.
2. Membersihkan spasi berlebih pada nama.
3. Mengubah nama menjadi title case.
4. Mengubah kode kelas menjadi huruf besar dan mengganti spasi dengan tanda hubung.
5. Menghitung jumlah kata dan membuat inisial nama.
6. Menampilkan hasil normalisasi.
